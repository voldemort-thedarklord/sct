# Smart Community Health — AI/ML Water-Borne Disease Risk Surveillance

An AI/ML-powered web application built with a **minimalistic dark theme** that combines real-world water-quality parameters, community symptom reports, environmental conditions, and historical disease records to classify localized water-borne disease risks (`Low`, `Moderate`, `High`, `Critical`), detect sensor anomalies, forecast 7-day outbreak trajectories, and trigger early warnings for health workers.

---

## Architecture & Technology Stack

| Layer | Technology | Location |
| :--- | :--- | :--- |
| **Frontend** | Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4 | `frontend/` |
| **Backend API** | Python FastAPI, Pydantic, Uvicorn | `backend/main.py` |
| **Database** | SQLAlchemy ORM (MySQL & SQLite compatible) + MySQL DDL | `backend/models.py`, `backend/schema.sql` |
| **AI/ML Pipeline** | Scikit-Learn (`RandomForestClassifier`, `IsolationForest`) & `XGBoost` (`XGBRegressor`) | `backend/ml_engine.py`, `backend/models_artifacts/` |
| **Data Processing** | Pandas & NumPy real-dataset cleaning pipeline | `backend/build_real_dataset.py`, `backend/data/` |
| **Geospatial Maps** | Leaflet + OpenStreetMap / CartoDB Dark Matter | `frontend/app/components/RiskMap.tsx` |
| **IoT Firmware** | ESP32 Multi-Sensor Telemetry Node (`.ino`) | `iot_esp32/esp32_water_monitor.ino` |

---

## Real-World Datasets & Trained Model Artifacts

Located in `backend/data/` and `backend/models_artifacts/`:
1. **`indian_cpcb_water_quality.csv`** (`1,991` stations) — Real Indian Central Pollution Control Board (CPCB / NWMP) river & groundwater stations (`PH`, `Temp`, `D.O.`, `Conductivity`, `B.O.D.`, `Fecal Coliform`, `Total Coliform`).
2. **`kaggle_water_potability.csv`** (`3,276` samples) & **`water_disease_dataset1.csv`** (`1,991` samples) — Real water potability benchmark (`ph`, `Hardness`, `Solids/TDS`, `Conductivity`, `Turbidity`, `Potability`).
3. **`waterborne_disease_data.csv`** (`1,000` samples) — River contamination parameters mapped to waterborne diseases (`Dysentery`, `Cholera`, `Typhoid`).
4. **`water_quality_disease_dataset.csv`** (`3,781` cleaned records) — Unified training corpus generated by `backend/build_real_dataset.py`.

## Quick Start

### 1. Start the Python FastAPI Backend (`http://localhost:8000`)
```bash
cd backend
.venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000
```

### 2. Start the Next.js Frontend (`http://localhost:3000`)
```bash
cd frontend
npm run dev -- --port 3000
```
